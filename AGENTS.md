# JCIE website agents

- For JCIE website content edits, publication requests, or questions about what the site editor can do, use `.agents/skills/jcie-site-editor/SKILL.md`.
- `CONTENT_GUIDE.md` is the editor-facing source map and capability guide. Check the relevant source files and current deployment workflow before acting.
- Preserve unrelated work in the checkout. Stage only files belonging to the requested change. Treat site redesigns and new functionality as development work outside the routine content-editing skill.
